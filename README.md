# React Form Validation App ✅

A simple **Form Validation application built using React**.  
This project validates user inputs in real-time and displays error messages for empty fields using React state management.

---

## 📌 Overview
This project demonstrates how to handle **form inputs, validation logic, and error handling** in React.  
It uses a clean UI with **Tailwind CSS utility classes** and animations powered by **animate.css**.

---

## ❓ Problem Statement
Form validation is a critical part of frontend applications.  
This project shows how to validate multiple input fields dynamically and display error messages without using any external validation library.

---

## 🛠️ Tools and Technologies
- React.js  
- JavaScript (ES6+)  
- Tailwind CSS  
- Animate.css  
- Vite  

---

## ⚙️ Features
- Multiple input fields validation  
- Real-time error messages  
- Required field validation  
- Controlled form inputs  
- Clean and responsive UI  
- Smooth animation on load

## 🧩 Key Concepts Used
